## Activity 3: Smartcare Problem Analysis
**Task 1**  
Stakeholder: Smartcare  
Needs: A software system to help with managing appointments.  
  
Stakeholder: Employees  
Needs: Software that streamlines work regarding managing appointments.  

Stakeholder: GPs  
Needs: Software that helps view and manage appointments.  
  
Stakeholder: Clients  
Needs: Better visibility in practitioner availability.  

**Task 2**  
Problem 1: Many different things are needed for the processing of an appointment.  
Problem 2: Booking availability and information is inconsistent.  
Problem 3: Cancellation requires a manual process.  
Problem 4: Operational reports are difficult to produce because of an accumulation of the above issues.  

**Task 3**  
Q1: How are admin, GPs, and clients meant to interact with the system?   
Q2: What actions does the system need to support?
Q3: Should the automated cancellation process work both ways, for the staff (admin/GP) and client?  
Q4: Should there be an automated notification sent to the client and/or GP regarding any appointment cancellations?  
Q5: Does and appointment require the client's and/or GP's information to be made?
